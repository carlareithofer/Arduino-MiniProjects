# 15 - Ultrasonic Distance Sensor with LEDs

An Arduino-based distance indicator that uses an ultrasonic sensor to measure the distance to nearby objects. Three LEDs indicate the distance range: red for objects under 50 cm, yellow for distances between 50 and 150 cm, and green for distances between 150 and 400 cm. The project uses hardware interrupts to detect the returning echo and calculate the distance.
