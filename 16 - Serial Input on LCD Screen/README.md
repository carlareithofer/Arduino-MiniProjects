# 16 - Serial Input on LCD Screen

An Arduino project that displays text on a 16×2 LCD using input from the Serial Monitor. Each new message is printed on an alternating row, replacing the previous content. Text longer than 16 characters is replaced with a warning message.

 **! Note**
- The LCD screen must have its pins soldered properly for the circuit to work.
