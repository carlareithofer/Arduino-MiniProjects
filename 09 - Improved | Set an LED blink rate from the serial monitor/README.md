# 09 - Improved | Set an LED blink rate from the serial monitor

In this mini project, I used the same setup as in the first, second, and eighth projects. In the previous project, if the blink rate was changed while the program was 
waiting in the *delay()* function, the new blink rate would only take effect at the end of the current cycle.

In this improved version, I removed the *delay()* function and used a different approach to control the LED's blink rate, allowing the new value to take effect immediately.
